# 测试约定

## 规则

1. **单元测试（每层必须）**：每一层的每个模块 / 组件实现都必须配套单元测试，覆盖正常路径、边界与失败路径。外部依赖（LLM / 向量库 / 数据源 / Memory / 下游层）一律用 mock 注入，单测不依赖真实外部服务。
2. **集成测试（层与层之间必须）**：相邻层之间（如 L4↔L5、L3↔L4、L3↔L5、L2↔L3）必须有集成测试，验证跨层契约（接口签名、数据模型、错误语义）真实可用；下游未就绪时用符合契约的桩/mock，就绪后替换为真实实现再跑一遍。
3. **正确性属性**：各层 design 中的 Correctness Properties 应有对应的属性测试（property-based，建议 hypothesis）。
4. **实现即测试**：完成一个任务即补齐其单测；完成一层即补齐与已就绪相邻层的集成测试。测试未通过不算任务完成。

## 适用范围

所有层（L5 / L4 / L3 / L2）的全部编码任务。
